4. INSTALLATION SUR IPHONE JAILBREAK
------------------------------------------------------------
Methode A — .deb via Filza / Sileo / Zebra
  1. Copier com.lkjkl90.ff2018menu_1.0.0_iphoneos-arm.deb sur l'iPhone
  2. Ouvrir avec Filza -> Installer (dpkg)
     ou  : dpkg -i com.lkjkl90.ff2018menu_1.0.0_iphoneos-arm.deb
  3. Respring

Methode B — dylib manuel
  1. Copier FF2018Menu.dylib dans :
       /Library/MobileSubstrate/DynamicLibraries/
  2. Creer /Library/MobileSubstrate/DynamicLibraries/FF2018Menu.plist :

       {
           Filter = {
               Bundles = (
                   "com.dts.freefireth"
               );
           };
       }

  3. Permissions :
       chown root:wheel FF2018Menu.dylib FF2018Menu.plist
       chmod 0644 FF2018Menu.dylib FF2018Menu.plist
  4. Respring :
       killall -9 SpringBoard
  5. Lancer Free Fire -> un bouton "FF" apparait, le menu s'ouvre
     automatiquement apres 2 s. Logs prefixe [FF2018] dans la console.

5. NOTES TECHNIQUES
------------------------------------------------------------
- Le binaire est FAT : il couvre les devices arm64 (A11 et anterieurs
  en mode arm64) et arm64e (A12+). Pas besoin de choisir une slice.
- Le hook MSHookFunction cible IL2CPP base + RVA 0x9093E4
  (Player.LateUpdate). Si le dylib est charge avant que libil2cpp
  soit mappe, le hook echoue silencieusement -> verifier
  "[FF2018] Hook installe" dans les logs. Le constructor attend 2 s
  pour laisser le moteur s'initialiser.
- Offsets (0x498..0x588 pour les HP, 0xA0 pour IsClientBot,
  0xCC pour TeamMapMark) sont ceux du dump 2018 : ils ne valident
  que sur la version de Free Fire correspondante.
- La CI tourne sur macos-latest (macOS 15 arm64, Xcode 26.6) avec
  Theos latest + ldid. Le workflow se declenche sur push main et
  manuellement via l'onglet Actions.
